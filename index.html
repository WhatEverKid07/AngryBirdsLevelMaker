Angry Bird Level Maker

A solo project to create a simple easy to use Angry Birds custom level maker.

About

This is a solo project I developed using Unity, inspired by my interest in Super Mario Maker 2 and Angry Birds. The goal was to create a custom level editor that allows players to build, save, test and share their own Angry Birds levels.

Process

Art/Visuals: I started with an existing Angry Birds port for Unity found on GitHub, which provided the original looking assets, physics, and core gameplay mechanics. With any further delevopments I plan to stick to this original style and personally it's my favourite.

Code: The project was developed using C# in Unity. One of the biggest challenges was creating the save system, which took considerable time to get working correctly. I had to work out how to store the objects placed within a level and then recreate them when loading a saved level. Alongside this, I implemented the object placement, navigation, and build and test modes.
